# Emmanuel Madrigal — Interactive Unity Developer Portfolio

Interactive blueprint-style portfolio dashboard built with HTML, CSS, and JavaScript. Showcasing 3D/2D game development projects, prototypes, augmented reality features, and software architecture practices.

Live Demo: https://tu-usuario.github.io/tu-repositorio/

## Features
- **Blueprint Industrial UI**: Custom technical grid styling with responsive components.
- **Categorized Project Showcase**: Filtering system for Prototypes, 3D, 2D, and Personal Projects.
- **Interactive Modals**: Detailed breakdowns for each project including gameplay media, architectural tasks, and links to playable builds / source code.

## Tech Stack
- HTML5 / CSS3 (Custom CSS Grid & Flexbox)
- JavaScript (Vanilla ES6+)
- Hosted via GitHub Pages
